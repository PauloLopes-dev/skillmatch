# Nome do Projeto

Skillmatch

Codigo em Javscript puro que avalia o perfil de um candidato com vagas disponiveis,calcula a compatibilidade percentual para cada vaga,escolhe a melhor vaga e apresenta uma lista indexada por ordem de ocorrencia das habilidades faltantes recomendando oque o candidato pode estudar para melhorar sua compatibilidade.

---

## 📌 Sobre o projeto

Codigo em Javscript puro que avalia o perfil de um candidato com vagas disponiveis,calcula a compatibilidade percentual para cada vaga,escolhe a melhor vaga e apresenta uma lista indexada por ordem de ocorrencia das habilidades faltantes recomendando oque o candidato pode estudar para melhorar sua compatibilidade.

---

## 🚀 Tecnologias utilizadas

- JavaScript
- Node.js
- Git / GitHub

Usado setTimeout para simular uma conexão entre cliente e servidor no mundo real uma requisição sai do computador cliente com arquitetura TCP/IP e protocolo http para realizar request e response enter cliente e servidor.
De maneira simples Cliente recebe o Front End do servidor que roda o Back End e mostra na tela do Navegador no lado cliente.
Pode haver interações entre estes dois polos nos dois sentidos e as pontas nem precisam mais estar no mesmo país ou continente e nem na Terra.

🚀 Nave Cliente
↓
🛰️ Satélite de comunicação
↓
📡 Estação terrestre
↓
🌐 Internet
↓
💻 Servidor
